# Build a Premium Indian Spices Brand Website

Create a premium, modern, visually rich **multi-page website for an Indian spices brand called “[BRAND NAME]”**.

The website should feel like a serious, established Indian FMCG/spices company — combining **Indian heritage, authentic spices, premium packaging, modern design, trust, quality, and strong storytelling**.

This is initially a **brand/portfolio website**, not a full e-commerce store. However, structure the architecture so e-commerce can be added later.

---

## 1. TECHNOLOGY STACK

Use:

- Next.js latest stable version
- TypeScript
- Tailwind CSS
- shadcn/ui where useful
- Framer Motion for animations
- Lucide React icons
- Responsive design
- Component-based architecture
- Clean reusable components
- SEO-friendly structure
- Optimized images
- Modern CSS animations

Do NOT create a generic template-looking website.

The final result should look like a professionally designed FMCG brand website.

---

# 2. BRAND DESIGN

## Overall Design Direction

Create a visual identity based on:

**Indian heritage + premium FMCG + modern minimalism**

Use:

- Warm ivory / cream backgrounds
- Deep spice red
- Dark maroon
- Turmeric yellow
- Saffron orange
- Earthy brown
- Charcoal/black text
- Subtle green accents where appropriate

Avoid making the entire website red.

Use cream/off-white as the primary background and use spice colors strategically for buttons, highlights and sections.

---

# 3. TYPOGRAPHY

Use a premium typography combination.

Headings:

- Playfair Display
OR
- Cormorant Garamond

Body:

- Inter
OR
- Manrope

Headings should feel editorial and premium.

Example:

"THE SOUL OF INDIA,
IN EVERY PINCH."

Large typography should be used throughout the website.

---

# 4. VISUAL STYLE

Use high-quality imagery of:

- Indian spices
- Turmeric
- Red chilli
- Coriander
- Cumin
- Cardamom
- Black pepper
- Cinnamon
- Cloves
- Garam masala
- Indian farms
- Farmers
- Traditional Indian cooking
- Premium spice bowls
- Spice powders
- Product packaging

Use large cinematic images.

Use subtle grain/noise textures.

Use soft shadows.

Use rounded corners moderately.

Do not overuse glassmorphism.

Do not use excessive gradients.

The website should feel premium and authentic.
